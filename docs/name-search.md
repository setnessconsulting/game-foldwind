# Public name search and decision

**Recorded:** 2026-11-15 (America/Los_Angeles)
**Decision:** public title **Foldwind**; repository `setnessconsulting/game-foldwind`.
**Tagline:** *A paper crane's flight.*

This is a good-faith search for a free GitHub Release, not a legal clearance
opinion. A future paid store release should repeat the search and get counsel
review.

## Why the title changed

The working title **Skyfold** was rejected after the search found:

- **SkyFold** by Trinit Games, a paper-plane flight game with progression:
  "Fold a paper plane, throw it from a mountain and turn every metre into your
  next upgrade." This is the same genre and a direct identity collision.
- **SKYFOLD** on itch.io, a separate game.
- **SKYFOLD REPUBLIC**, USPTO serial 99548201, filed in the games/toys class.
- **Skyfold Inc.**, a registered mark for vertically folding movable walls.
  Different product class, but still a public-name conflict.

A game called Skyfold cannot be presented as an original identity when a
same-genre game already uses the name and a games-class trademark filing
exists.

## Candidates checked

| Candidate | Finding | Result |
|---|---|---|
| **Skyfold** | Trinit Games paper-plane flight game; itch.io game; SKYFOLD REPUBLIC USPTO filing; Skyfold Inc. walls | Rejected |
| **Featherline** | Asterism Labs medication tracker; FEATHERLINE AI trademark | Rejected |
| **Emberwing** | Multiple games, including a cozy arcade flight game and a dragon-flight game | Rejected |
| **Foldlight** | Existing light-bending puzzle game | Rejected |
| **Lanternwing** | Existing one-button Godot game about a moth and lanterns | Rejected |
| **Foldwind** | No exact game or trademark found in the searched sources | **Selected** |

## Decision rule

- The public title, repo, README, release page, and store copy use **Foldwind**.
- The internal label `game-flappy-bird` is retired from public copy and remains
  only as historical planning shorthand if it appears in old evidence.
- No *Flappy Bird* name, bird design, pipes, ground strip, score font, sounds,
  or store copy are used.
- Before any paid store release, repeat the search for `Foldwind` and record
  the result. If a conflict appears, use a new original title rather than
  trading on an existing one.
